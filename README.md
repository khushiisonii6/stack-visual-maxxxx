# DataStruct Studio 🚀

**DataStruct Studio** is an interactive, full-featured Data Structures & Algorithms (DSA) learning laboratory and simulation platform built with React, Vite, TypeScript, and Tailwind CSS.

![DataStruct Studio Logo](./assets/logo.svg)

---

## 🌟 Key Features

- 📊 **Interactive Data Structure Visualizers**:
  - **Arrays & Dynamic Arrays**: Push, Pop, Insert, Delete, Access with dynamic index highlighting.
  - **Singly & Doubly Linked Lists**: Node insertion at head/tail, deletion, and node traversal animations.
  - **Stacks**: LIFO operations with Stack Overflow/Underflow protections and visual pointer tracking.
  - **Queues & Circular Queues**: FIFO enqueue/dequeue, wrap-around index management, and front/rear pointers.
  - **Binary Search Trees (BST) & Trees**: Animated insertion, deletion, and pre-order/in-order/post-order traversals.
  - **Min / Max Heaps**: Visual binary heap tree & array representations with heapify-up and heapify-down steps.
  - **Graphs**: Node creation, edge weighting, BFS, DFS, and Dijkstra's Shortest Path graph traversals.
  - **Hash Tables**: Key-value mapping, hash function computation, and linear probing collision resolution.
  - **Priority Queues**: Min/Max priority queue scheduling with dynamic element reordering.

- ⚡ **Sorting & Searching Simulators**:
  - **Sorting Algorithms**: Bubble Sort, Selection Sort, Insertion Sort, Quick Sort, Merge Sort, Heap Sort with speed controls, step-by-step playback, comparison counters, and swap highlights.
  - **Searching Algorithms**: Linear Search and Binary Search with pointer tracking and search status feedback.

- 💡 **Multi-Language Code Snippets**:
  - Code implementations in **Python**, **Java**, **C++**, and **JavaScript** for every data structure and algorithm.
  - Built-in one-click code copy and syntax-highlighted tabs.

- 🧠 **Interactive Quizzes & Mastery Progress**:
  - Multiple-choice assessment quizzes for each data structure module.
  - Automatic scoring, instant answer explanations, and persistent local completion tracking.

- 🎮 **DSA Mini-Games Hub**:
  - **Stack Tower Challenge**: Test your LIFO stack manipulation under move constraints.
  - **Sorting Speedrun**: Arrange random array blocks manually or identify sorting pass steps against time.
  - **Tree Traversal Puzzle**: Predict exact traversal orders for binary tree structures.

- 📐 **Big-O Complexity Matrix**:
  - Comparative analysis matrix showing Time Complexity (Best, Average, Worst) and Space Complexity for all operations.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) installed on your system.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/datastruct-studio.git
   cd datastruct-studio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000` to explore DataStruct Studio.

---

## 📦 Scripts

- `npm run dev`: Starts the local Vite development server on port 3000.
- `npm run build`: Builds the production bundle in the `dist/` directory.
- `npm run start`: Runs the built app in production mode.
- `npm run lint`: Runs TypeScript type-checking and linter checks.
